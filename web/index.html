    Din dator kör. Webben visar.

    Du kan lägga upp sidan på Vercel direkt. Med en livekoppling följer resultaten med automatiskt, utan en ny Git-push för varje träningspass.

    01

    Publicera på Vercel

    Importera GitHub-repot oskar-cloud/Geodaish. Använd projektets rotmapp.

    Framework
    Other
    Build command
    npm run build
    Output directory
    dist

    Inställningarna finns redan i vercel.json. Sparade resultat och uppspelningen fungerar direkt.

    Öppna Vercel
    02

    Aktivera liverapporter

    Koppla Upstash Redis via Vercels Storage/Marketplace och kontrollera att projektet får REST-URL och token.

    Lägg till en egen hemlig miljövariabel TRAINING_API_TOKEN med minst 32 tecken och gör en ny deployment.

    Servern stöder UPSTASH_REDIS_REST_URL/TOKEN och KV_REST_API_URL/TOKEN. Nycklarna ligger bara på servern.

    Läs hela installationsguiden
    03

    Starta ett träningspass på datorn

    Aktivera din Python-miljö. Ange webbadressen och samma hemliga nyckel som på Vercel. Rapportering sker ungefär var femte sekund och vid varje validering.

    Lokalt: kör npm run dev och geodaish train i två terminaler. Då behövs varken Redis eller någon nyckel. Kör ett träningspass åt gången per dashboard.
