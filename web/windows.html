Starta med förhandsvisning. Armera med F8 i spelet och stoppa med F9 eller den lokala STOP-knappen.

Koppla speldatorn

Publicera repot på Vercel och koppla Upstash Redis samt TRAINING_API_TOKEN. Ange samma nyckel och webbplatsens adress på Windows-datorn enligt guiden.

.\.venv\Scripts\python.exe -m geodaish windows run --profile runs/windows/profile.json --model models/demo-normal.zip --jump-key up --stream-frames

Installation, kalibrering och Vercel →

Rapporter uppdateras ungefär varje sekund och hämtas varannan sekund. Bildvisningen är ögonblicksbilder, inte 60 FPS-video. Utan --stream-frames visas bara upptäckta objekt. Spel och styrning körs på datorn; webbplatsen visar deras rapporter.
